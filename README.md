# 🪐 Mars Odyssey Pro — Competition Edition

![GitHub license](https://img.shields.io/badge/Version-1.0.0-orange)
![Mars Mission](https://img.shields.io/badge/Mission-Mars%202026-red)

Цей проект є **інтерактивною мультимедійною платформою**, присвяченою дослідженню Марса. Він поєднує в собі освітній контент, ігрові механіки та сучасний футуристичний дизайн у стилі *Glassmorphism*.

> **Створено спеціально для конкурсу "Марс 2026".**

---

## 🚀 Основні розділи та функції

### 1. 🚜 Керування Ровером (Surface Navigation)
Інтерактивний симулятор марсохода прямо у браузері.
*   **Механіка:** Керування здійснюється клавішами `WASD` або стрілками.
*   **Завдання:** Досліджуйте поверхню на сітці 10x10, збирайте зразки (позначені зірочкою ★).
*   **Телеметрія:** В реальному часі відображаються координати та журнал подій місії.

### 2. 🧪 Лабораторія "Генезис" (Bio-Lab)
Міні-гра, що імітує генетичні дослідження майбутнього.
*   **Функція:** Змішуйте ДНК різних організмів (Кактус, Мох, Лішайник).
*   **Результат:** Система аналізує сумісність і показує, чи здатна створена рослина вижити в суворих умовах Марса.

### 3. 🛰 Супутники Марсу
Детальна інформація про природні супутники планети — Фобос та Деймос.
*   Включає реальні зображення та короткі наукові довідки.
*   Додано прямі посилання на ресурси **NASA** для глибшого вивчення.

### 4. 📂 Архів Марсіанських місій
Каталог найважливіших експедицій людства до Червоної планети.
*   Використовує реальні фотографії роверів *Perseverance*, *Curiosity* та станції *Mars Express*.
*   Містить опис технічних досягнень кожної місії.

---

## 🎨 Дизайн та Інтерактив
*   **Stars Canvas:** Динамічний фон із мерехтливими зірками (HTML5 Canvas).
*   **Quick Fact:** Кнопка у навігації, що видає випадковий цікавий науковий факт.
*   **Space Modern Style:** Темна палітра з акцентом на "марсіанський оранжевий" (`#ff4d00`).
*   **Шрифти:** `Inter` для читабельності та `Orbitron` для футуристичного вигляду.

---

## 🛠 Технології
Проект побудований на чистому стеку технологій (Vanilla Stack):
*   **HTML5:** Семантична верстка та Canvas API.
*   **CSS3:** Flexbox, Grid, Glassmorphism ефекти, анімації при прокручуванні (reveal).
*   **JavaScript:** Логіка ровера, механіка ДНК та динамічний рендеринг.
