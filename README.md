│    освітній контент, ігрові механіки та сучасний футуристичний дизайн (Glassmorphism). Створено спеціально для │

│  4 +                                                                                                           │
│  5 + ## 🚀 Основні розділи та функції                                                                          │
│  6 +                                                                                                           │
│  7 + ### 1. **Керування Ровером (Surface Navigation)**                                                         │
│  8 + Інтерактивний симулятор марсохода прямо у браузері.                                                       │
│  9 + - **Механіка:** Керування здійснюється клавішами **WASD** або стрілками.                                  │
│ 10 + - **Завдання:** Досліджуйте поверхню на сітці 10x10, збирайте зразки (позначені зірочкою ★).              │
│ 11 + - **Телеметрія:** В реальному часі відображаються координати та журнал подій місії.                       │
│ 12 +                                                                                                           │
│ 13 + ### 2. **Лабораторія "Генезис" (Bio-Lab)**                                                                │
│ 14 + Міні-гра, що імітує генетичні дослідження майбутнього.                                                    │
│ 15 + - **Функція:** Змішуйте ДНК різних організмів (Кактус, Мох, Лішайник).                                    │
│ 16 + - **Результат:** Система аналізує сумісність і показує, чи здатна створена рослина вижити в суворих       │
│    умовах Марса.                                                                                               │
│ 17 +                                                                                                           │
│ 18 + ### 3. **Супутники Марсу**                                                                                │
│ 19 + Детальна інформація про природні супутники планети — Фобос та Деймос.                                     │
│ 20 + - Включає реальні зображення та короткі наукові довідки.                                                  │
│ 21 + - Додано прямі посилання на ресурси NASA для глибшого вивчення.                                           │
│ 22 +                                                                                                           │
│ 23 + ### 4. **Архів Марсіанських місій**                                                                       │
│ 24 + Каталог найважливіших експедицій людства до Червоної планети.                                             │
│ 25 + - Використовує реальні фотографії роверів **Perseverance**, **Curiosity** та станції **Mars Express**.    │
│ 26 + - Містить опис технічних досягнень кожної місії.                                                          │
│ 27 +                                                                                                           │
│ 28 + ### 5. **Інтерактивні елементи**                                                                          │
│ 29 + - **Stars Canvas:** Динамічний фон із мерехтливими зірками, створений на HTML5 Canvas.                    │
│ 30 + - **Quick Fact:** Кнопка у навігації, що видає випадковий цікавий науковий факт про Марс.                 │
│ 31 + - **Scroll Progress:** Візуальний індикатор у верхній частині сторінки, що показує прогрес перегляду.     │
│ 32 +                                                                                                           │
